# 第4章 デバッグ演習：ステータス一括更新のバグ

## 進め方

1. 下記の「バグ報告」だけを読んだ状態で、Claude Codeに調査を依頼してください
   （`src/taskStatus.ts` の中身を先に読んでしまうと演習の効果が薄れます）。
2. 「再現 → 切り分け → 診断 → 修正」の流れで進めます。まずは `tests/taskStatus.test.ts` の
   失敗するテストを再現することから始めてください。
3. 原因を特定したら、Claude Codeに修正方針を説明させてから実際に修正してもらってください。
4. 最後に、今回のバグを防ぐための追加テストケースも1つ以上、一緒に考えて追加してください。

```bash
cd exercises/debug-task-status
npm install
npm test
```

## ヒント（詰まった場合のみ開く）

<details>
<summary>ヒント1</summary>

「画面をリロードすると直っている」というのは、サーバー側のデータは壊れておらず、
**クライアント側のメモリ上のデータ**だけが書き換わっている可能性を示唆しています。
</details>

<details>
<summary>ヒント2</summary>

JavaScript／TypeScriptでは、配列やオブジェクトを関数に渡すと「参照」が渡されます。
関数の中でその中身を直接書き換えると、呼び出し元が持っている変数の中身も一緒に変わって
しまうことがあります。
</details>
