# src/lib

複数の画面・APIルートから使い回すロジックを置くフォルダです。

## すでに用意されているファイル（実装済み・演習対象外）

- `prisma.ts` — PrismaClient のシングルトンインスタンス
- `auth.ts` — GitHub OAuth による認証設定（NextAuth）

これらは認証機能を動かすために必要なファイルです。演習では変更しません。

## 第3章以降で追加していくファイルの例

- `tasks.ts` — タスクのステータス更新など、ビジネスロジック
- `projects.ts` — プロジェクトに関する処理

必要に応じて Claude Code と相談しながら、適切な単位で切り出してください。
